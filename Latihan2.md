Langkah 1 — Buat direktori project_Sistem_Operasi_B di home
```
cd ~
```
```
mkdir project_Sistem_Operasi_B
```

Langkah 2 — Di dalamnya buat folder src, doc, dan data
```
cd project_Sistem_Operasi_B
```
```
mkdir src doc data
```

Langkah 3 — Buat file kosong README.md dan src/main.sh
```
touch README.md src/main.sh
```
- touch digunakan untuk membuat file kosong.
- File main.sh nantinya bisa diisi skrip shell jika diperlukan.

Langkah 4 — Tampilkan ukuran direktori project_Sistem_Operasi_B dalam format yang mudah dibaca
```
du -sh ~/project_Sistem_Operasi_B
```

Hasil Akhir
Setelah semua langkah di atas, struktur direktori kamu akan terlihat seperti ini:
```
project_Sistem_Operasi_B/
├── data/
├── doc/
├── src/
│   └── main.sh
└── README.md
```
